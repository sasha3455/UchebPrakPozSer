# Калькулятор и конвертер валют

Flutter Web-приложение для практической работы №1 «Маршрутизация, формы и URL как состояние».

## Запуск

```bash
flutter pub get
flutter run -d chrome --web-port=5555
```

Проверка качества:

```bash
flutter analyze
flutter test
flutter build web
```

Готовая релизная версия после сборки находится в `build/web`.

## Схема маршрутов

| Адрес | Экран |
| --- | --- |
| `/` | Главная страница |
| `/calculator` | Форма калькулятора |
| `/calculator/result?a=12&op=%2B&b=5` | Результат вычисления |
| `/converter` | Форма конвертера |
| `/converter/result?amount=100&from=USD&to=EUR` | Результат конвертации |
| Любой неизвестный адрес | Экран 404 |

Форма собирает введённые данные, проверяет их и передаёт в query-параметры URL. Экран результата читает параметры непосредственно из адреса, поэтому может открываться напрямую в новой вкладке. Некорректные параметры выводят понятную ошибку вместо исключения.

В приложении реализованы светлая и тёмная темы, сохранение выбранной пары валют в браузере и адаптивная ширина форм. Вычисления и конвертация вынесены в `lib/logic`, а тесты находятся в `test`.
